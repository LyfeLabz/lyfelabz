## Governing evidence model

**Student performance → evidence generation → retention → teacher visibility → interpretation** are separate questions, not an automatic pipeline. Completion, correctness, evidence quality, independence, and individual authorship are not interchangeable.

**Retain instructional evidence, not telemetry.** Paper, physical artifacts, and teacher observation can provide legitimate evidence without full digital duplication.

## Amplitude as an exemplar

Amplitude is one of the strongest existing digital scientific-investigation experiences. Its evidence is simulation-generated, not physical measurement. The local chain is **prediction → trials → data/graph → model comparison → reasoning/CER**. A programmed amplitude–energy relationship supplies simulated outcomes; students choose trials and use numbers to reason.

The submission preserves CER but not the complete underlying history. Session storage is not a cumulative teacher record. The omission limits a teacher's ability to reconstruct the argument, without negating the student performance.

## Teacher interpretation layers

Backend possession → client retrieval → Workspace presentation → useful interpretation each needs evidence. Investigation 8 found narrower teacher-facing projections than backend data and incomplete historical writing context. A score, item ID, or text without task context can limit interpretation.

Teacher Workspace is not the sole legitimate evidence location. Google Classroom routing, grade passback, or submission success does not establish a complete student evidence portfolio or teacher review. Physical work is not defective simply because it is outside Workspace.

## Evidence-loss distinctions

| Type | Example |
| --- | --- |
| Generation/performance | Undeveloped physical PS1-6/PS1-8 |
| Capture/handoff | Omitted writing or meaningful trial/configuration data |
| Persistence | Prototype Ball Run structured answers not retained |
| Attribution | Team product or editable name mistaken for individual performance |
| Provenance | Missing historical writing prompt/content context |
| Retrieval/presentation | Retained data absent or narrowed in teacher display |
| Interpretation | Evidence lacks adequate task context or evaluation guidance |
| Longitudinal continuity | Unrecorded retries or disconnected iterations |
| Physical/digital connection | Necessary classroom evidence cannot be connected to the claim being reviewed |

An off-platform artifact is not automatically a gap. The issue is whether the instructional claim can be supported and interpreted.

## Appropriate retention and future decisions

Useful longitudinal evidence can include writing across genuine attempts, plans/results/conclusions, quantitative trial histories including failures, meaningful model evaluations, engineering drawings/revisions, individual reflections/logs, and concise teacher observations.

Hovers, animation frames, decorative clicks, repeated navigation, disposable practice, and redundant intermediate states need not be retained. Retention depth and teacher access remain curriculum/product decisions; this record defines no schemas or contracts.

Future verification should establish deployed submission behavior, real teacher retrieval, retry/attempt semantics, historical prompt reconstruction, legacy endpoint receipt, and classroom artifact practices.
