## Governing interpretation

**Modeling performance should match the actual Massachusetts standard and instructional purpose.**

Grade 6 provides substantial supplied-model interpretation and use, bounded representation, and a strong local model-evaluation example. Complete independent development is less securely established where the actual standards require it. This does not support a generic prescription to make students create more models everywhere.

## Distinct performances

| Action | Evidence it establishes |
| --- | --- |
| Seeing | Exposure to a representation |
| Reading | Identifying its depicted components/conventions |
| Interpreting | Explaining represented relationships |
| Using | Applying a model to explanation, prediction, or investigation |
| Developing | Authoring relevant components/relationships in a representation |
| Evaluating | Judging a model against evidence, purpose, or limits |
| Revising | Changing the representation/relationships for a reason |

Changing a slider is not automatically developing or revising the scientific model. Receiving a model answer is not authoring one. A verbal conceptual model may be substantive; drawing quality is not the definition of modeling.

## Standard-specific distinctions

| Standard | Required performance focus | Reconciled evidence |
| --- | --- | --- |
| ESS1-1a | Develop and use | Phase/eclipse model use and causal writing are substantial; complete developed-and-used representation remains unestablished |
| LS1-2 | Develop and use | Organelles and required Cell Energy support functional reasoning; complete student-developed cell-function model remains unestablished |
| PS1-7(MA) | Use a particulate model and proportional reasoning | Judge integration of particles and density explanation, not an invented independent drawing requirement |
| PS4-1 | Use wave diagrams | Nature of Waves plus Amplitude provide representation, data, and model comparison |
| PS4-2 | Use diagrams/other models | Existing wave-behavior use counts; do not substitute national NGSS development wording |
| ESS1-5(MA) | Use graphical displays | Supplied displays plus own-word nested relationships count; independent graphical construction is not required |
| ETS1-5(MA) | Create engineering representations using scale/proportion | Physical scaled drawings are engineering evidence, not relabeled scientific-model development |

Scientific-model revision is part of a broader practice progression, not a universal explicit Grade 6 PE requirement. Massachusetts wording controls these distinctions. [Massachusetts Grade 6 framework](https://www.doe.mass.edu/frameworks/scitech/2016-04.pdf#page=57).

## Experience-level findings

- Eclipse Alignment and Gravity Wells provide meaningful supplied-model use and prediction/configuration changes, with incomplete retained histories.
- Cell Energy develops causal functional understanding; more biochemical complexity does not by itself establish greater model authorship.
- Body Systems maps support systems reasoning through supplied relationships. The separate sprint response provides meaningful individual synthesis.
- Floatlandia is a constrained reconstruction; Fossil Hunt is geological correlation/ordering with scientific qualifications. Neither creates a universal scientific-model-development obligation for analytical standards.
- Amplitude compares supplied mathematical models against student-generated simulated data. This is model evaluation, not invention or revision of the candidate models.
- Ball Run and Build-a-Boat have stronger sustained construction, testing, and revision. Preserve those engineering identities.

## Evidence and future judgment

Models can be physical, graphical, conceptual, or verbal as appropriate to the standard. Retain meaningful representations and reasoning where needed for interpretation, rather than every interface movement. Team-created models need individual attribution before individual claims.

Earlier broad HQIM-5 “model revision missing” language is a progression diagnostic, not a new required task across all standards. Future review should focus on ESS1-1a/LS1-2 sufficiency and actual task purpose. No new modeling activity is commissioned, and no HQIM-3A letter changes.
